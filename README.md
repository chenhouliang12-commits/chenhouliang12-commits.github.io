# 午夜钟表匠的工坊

公开试玩：<https://chenhouliang12-commits.github.io/>


一款纯 HTML + CSS + 原生 JavaScript 的单机网页密室逃脱游戏。双击 `index.html` 即可游玩，无需联网、无需安装依赖。

## 运行方式

- 直接双击 `index.html`，用任意现代浏览器打开即可。
- 也可以通过 `启动本地入口.bat` 启动本地服务器。
- 手机与桌面浏览器均可（响应式 + 触屏）。

## 操作说明

- **点击场景中的物体**：观察、拾取物品、触发机关。
- **高亮**（右上角 ✨）：显示当前房间所有可交互热点。
- **背包**：点击物品选中它；再点击场景物体即可「使用」；再点一次已选中的物品可查看详情；选中一件物品后点另一件物品可尝试「组合」。
- **笔记本**（右上角 📓）：随时回看已发现的线索。
- **提示**（右上角 💡）：每个谜题有 3 级提示，逐级展开，使用次数会影响结局评级。
- **设置**（右上角 ⚙️）：音效、环境音、文字大小、重新开始。
- **保存**（右上角 💾）：立即保存当前进度；游戏也会在关键操作后自动存档。

## 调试面板

按键盘 `~` 键（反引号）可唤出开发者调试面板，支持跳转房间、给予物品、查看所有答案、重置。

## 文件结构

```text
index.html               页面入口
css/style.css            样式与响应式布局
js/data.js               物品、谜题答案、提示、房间热点数据
js/engine.js             状态、存档、交互、谜题判定、结局评级
js/ui.js                 背包、弹窗、笔记本、提示、设置、结局界面
js/scene.js              房间图片渲染、热点交互、校准编辑器
js/audio.js              WebAudio 合成音效
js/main.js               初始化入口
assets/scenes/*.jpg      前厅、地下室、阁楼场景图
DESIGN.md                游戏设计文档
SELF_CHECK.md            设计自查结果
WALKTHROUGH.md           完整攻略
server.js / 启动本地入口.bat  可选的零依赖本地服务器
```

## 更换主题 / 图片素材

- 文案、物品、谜题答案集中在 `js/data.js`。
- 三个房间背景图位于 `assets/scenes/foyer.jpg`、`basement.jpg`、`attic.jpg`。替换时保持文件名和画面比例即可。
- 热点坐标与图片尺寸对应，定义在 `js/data.js` 的 `window.HOTSPOTS` 中。

## 校准热点（开发功能）

1. 使用 URL 参数打开：`index.html?hotspots=1`。
2. 按 `E` 进入热点校准编辑器。
3. 可拖动顶点、绘制多边形或使用魔棒，完成后导出 JSON。
4. 将导出的热点数据回写到 `js/data.js`。
5. 正式游戏默认始终使用 `data.js`，不会读取旧校准缓存，避免不完整的坐标覆盖关卡热点。

## 自动检查

```bash
node _smoke_test.js
```

该脚本会模拟一条完整通关路线，检查谜题状态、道具获取和结局触发。

## 通关要点（无剧透）

每个谜题的答案都能在游戏内找到线索推导出来，不需要外部知识。卡住时优先使用右上角的分级提示。
